# G2–G9 执行问题与解决记录

更新时间：2026-09-01

本记录只描述本轮按新计划推进时遇到的问题、证据、处理思路和验证结果；不把未验证的目标能力写成已完成。

## 统一解决流程

1. 先保留原始错误、退出码、运行配置和影响范围，不直接重试覆盖证据。
2. 将问题分类为依赖、数据/解码、模型输入、接口契约、性能或服务竞态，避免把所有问题归因于 Grounding。
3. 设计只改变一个主要变量的最小修复；大型权重和缓存写入外置数据目录，失败实验使用新目录。
4. 先做最小 smoke，再做固定 pilot，最后运行项目回归测试；质量、延迟和资源指标分开记录。
5. 修复通过后同步 `docs/project_state.md`、对应 Gate 文档和本问题日志；未通过项保持 pending，并给出下一项最直接验证任务。
